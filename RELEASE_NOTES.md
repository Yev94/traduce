# Traduce 1.0.0

Primera versión independiente para Windows 10/11 x64.

- Alt+T selecciona una región; OCR local antes de enviar una imagen.
- Español a inglés y otros idiomas a español.
- Codex y Claude Code mediante sus clientes oficiales; OpenAI, Claude, Gemini, OpenRouter, Ollama y APIs compatibles.
- Pantalla de conexión con instalación del cliente, inicio de sesión oficial, claves protegidas y selección de modelo.
- Ventana compacta con el ancho del recorte, siempre visible y compatible con varias pantallas.
- Registros locales por aplicación y modo texto/imagen, sin guardar contenido.

Descarga **Traduce-Setup.exe** para instalar sin administrador, o **Traduce-Windows-x64.zip** para extraer y ejecutar. Los ajustes de la versión anterior se conservan. La primera apertura en otro ordenador guía la conexión.

Validación: contratos HTTP simulados para todos los adaptadores; pruebas locales de interfaz/OCR/arranque y captura en dos monitores. Codex se comprueba también con peticiones reales de texto e imagen. Claude Code y las APIs requieren una cuenta/clave propia; su traducción real no se ha verificado con credenciales en esta publicación.

La compatibilidad de imágenes depende del modelo. Las suscripciones y las APIs tienen sus propios límites. Esta versión todavía no está firmada por un editor.
