# Traduce 1.1.0 · Español / English

## Español

- Nuevo logo con transparencia, integrado en el ejecutable, la ventana, la bandeja y el instalador.
- Interfaz completa en español e inglés. Elige **Ajustes → Idioma de la interfaz → Guardar**; cambia sin reiniciar y conserva la elección.
- README completo en ambos idiomas, con el logo y capturas reales de las ventanas.
- Proyecto público y de código abierto bajo licencia MIT.

Descarga **Traduce-Setup.exe** para instalar o actualizar sin administrador, o **Traduce-Windows-x64.zip** para extraer y ejecutar. Se conservan las cuentas, los ajustes y los registros. El idioma de la interfaz no cambia la dirección de traducción: español → inglés; otros idiomas → español.

Validado con 133 comprobaciones locales, incluyendo cambio de idioma, persistencia, mensajes, tamaño de botones, OCR y arranque. Las pruebas ordinarias utilizan respuestas simuladas de los proveedores. El funcionamiento real de Codex con texto e imagen se validó en 1.0.0; las APIs y Claude Code aún requieren validación con sus cuentas. Los ejecutables siguen sin firma de editor.

## English

- New transparent logo in the executable, window, system tray and installer.
- Full Spanish and English interface. Choose **Settings → Interface language → Save**; no restart required, and your choice is remembered.
- Full README in both languages, with the logo and real window screenshots.
- Public, open-source project under the MIT license.

Download **Traduce-Setup.exe** to install or update without administrator access, or extract and run **Traduce-Windows-x64.zip**. Accounts, settings and logs are preserved. Interface language does not change the translation direction: Spanish → English; other languages → Spanish.

Validated with 133 local checks covering language switching, persistence, messages, button sizing, OCR and startup. Ordinary tests use simulated provider responses. Actual Codex text and image translation was validated in 1.0.0; APIs and Claude Code still require validation with their own accounts. Executables remain unsigned.
