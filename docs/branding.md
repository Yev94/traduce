# Identidad visual / Visual identity

## Español

Logo generado con la herramienta integrada de generación de imágenes el 1 de octubre de 2026, con fondo transparente. El PNG original se conserva en `assets/logo.png`. `scripts/make-icon.ps1` lo convierte a un ICO con tamaños de 16, 20, 24, 32, 40, 48, 64, 128 y 256 px, manteniendo el canal alfa. El logo y las capturas se distribuyen con el proyecto bajo la licencia MIT.

Concepto: dos bocadillos superpuestos en tonos menta, turquesa y azul, con una T que representa Traduce. Las capturas de los dos README proceden de las ventanas reales de la aplicación con textos de ejemplo; no son montajes generados por IA.

## English

Logo generated with the built-in image generation tool on October 1, 2026, with a transparent background. The original PNG is stored at `assets/logo.png`. `scripts/make-icon.ps1` converts it into an ICO at 16, 20, 24, 32, 40, 48, 64, 128 and 256 px while preserving alpha. The logo and screenshots are distributed with the project under the MIT license.

Concept: two overlapping speech bubbles in mint, turquoise and blue, with a T representing Traduce. Both READMEs use screenshots of the actual app windows with sample text, not AI-generated UI mockups.

## Prompt original / Original prompt

> Use case: logo-brand. Create one polished original logo symbol for Traduce, a compact Windows app that translates selected screen regions between languages. Asset: transparent PNG app icon and README logo, square 1024x1024 canvas. A single elegant compact mark formed by two overlapping rounded speech bubbles, with their geometry / negative space subtly suggesting a capital T and the exchange of language. Strong distinctive silhouette, generous bold forms, carefully balanced optical alignment, immediately recognizable at 16 and 32 pixels. Contemporary premium software identity, restrained subtle shading, almost vector-like crisp edges. Palette fits the existing app: luminous mint/turquoise and deep teal with a small blue accent, readable on both dark navy and white. Center the mark and let it occupy about 85% of the canvas. Actual alpha transparency everywhere outside the mark. No background plate, no checkerboard, no mockup, no external shadow, no border, no watermark, no words or extra letters, no multiple alternatives. Deliver only the single finished icon on transparent background.
